# DwarfX

DwarfX is an independent software and games studio.

## Site structure
- `index.html` — studio home
- `apps.html` — app directory
- `apps/` — individual app tracks
- `games.html` — game directory
- `games/2d.html` — 2D catalog
- `games/3d.html` — 3D catalog
- `games/2d/` and `games/3d/` — genre pages
- `contact.html` — direct contact
- `assets/` — brand assets and favicon

The site is intentionally static so it can run cleanly on GitHub Pages without a build step.
